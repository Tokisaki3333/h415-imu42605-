## 0. 四条判据（缺一不可！）

| 判据 | 工具 | 说明 |
|---|---|---|
| **① 倾角 dip** | `mag_site_check.py`、`mag_dip_tilt.py` | dip = ∠(m̂, ĝ) − 90°（**姿态无关**），必须 = **54.330 ± 0.5°**。**对"绕竖直的旋转/镜像"完全不敏感。** |
| **② 偏航符号** | `mag_yaw_sense.py` | 绕竖直转时须有 `dm/dt = −ω × m`：判 `corr(d·az/dt, −ω_z)`，**斜率必须 ≈ +1.0**；≈ −1 就是镜像（牵引方向反了）。 |

| **④ 倾角不变性** | `mag_dip_tilt.py` | body dip 必须与**倾角无关**。世界系固定干扰只能产生与倾角无关的恒定偏置；**dip 随倾角摆动 = A/C 的真实缺陷**。 |

**教训 1**：VER=112 只过①不过②（斜率 −1.007），被用户抓到"牵引方向彻底错误"。`dip` 对上、镜像解也能对上 ⇒ **只报 dip 一致就上机是错的**。
**教训 2**：①②对"恒定方位偏置"全都瞎。113/114 那轮就是这么坏的（见 §6）。
**教训 3（我犯过）**：`mag_heading_datum.py` 里 up 轴必须取 **û = +ĝ**。加速度计静止测的是**比力**，+z 朝上读 +1 g，所以 +ĝ 就是世界 up（`mag_dip_tilt.py` 用 +ĝ 得到 +54° 也证明这一点）。取 −ĝ 会让 θ 反号，得到**镜像的假象**——我曾据此误报"A 是左手系、航向被镜像"，已撤回。

#### 8.5.1 要抵消的漂移率 = 1000 ppm × 满量程 = 2 dps（**不是** 1.23 deg/h）

- `0.58 deg/√h`、`1.23 deg/h` 这类数只描述**静止**。一旦有转动，主角变成**标度/交叉轴误差**：
  用户口径 **满量程 1000 ppm**，ICM-42605 量程 **±2000 dps**（16.4 LSB/dps，`v5f_tune.h` 141 行）
  ⇒ 不可建模漂移率 = 1000e-6 × 2000 dps = **2 dps = 7200 deg/h**（比例于 |w|，零偏跟踪器拿不掉）。
- 所以"够抵消陀螺漂移速度"必须按 **k_s·|w|** 量化；按 1.23 deg/h 设计的 τ=600 s 是错的：
  300 dps 下跟不上，稳态滞后 **5.8°**（见 8.5.2 对比行）。

#### 8.5.2 设计准则：**牵引稳态滞后 = 漂移率 × τ ≤ σ_mag = 2°**

```
滞后 = k_s·|w|·τ  ≤  σ_mag = 2 deg   （σ_mag = 地磁自身误差，S3 实测残差 p50 1.7~2.15 deg）
最坏点 |w| = FS = 2000 dps  ->  τ(FS) = 2 deg / 2 dps = 1.00 s
R_yaw = Q(FS)·τ²·h²/dt_e = 1.2185e-03 · 1.0 · 0.3400 / 0.00199501 = 0.2077 rad²
```

`τ ∝ 1/|w|`（因为 Q ∝ w²），所以**滞后在所有速率上都是同一个 2.0°**：一个 τ 内转过 2000°，
标度误差正好累积 `k_s·2000 = 2.0°` = 地磁自身误差 —— 即"牵引速率恰好等于漂移速率，一个不多一个不少"。
这就是"尽量慢"与"能抵消漂移"的唯一交点，也自动满足"陀螺 Q 大了地磁才拉得快"（无门、无开关、不抖）。

### 8.7.4 "先前讨论值 2 dps" 如何被严格卡住

- 先前讨论值 = 陀螺**满量程不可建模漂移率** = 1000 ppm × FS(2000 dps) = **2 dps = 7200 deg/h**。
- 标准 KF 里修正速度 = 误差/τ，所以"卡严 2 dps"等价于 **τ ≥ 1 s**（在误差 ≤ 地磁自身误差 2° 的范围内）：
  `τ = dt·sqrt(R/(Q·dt))/h ≥ 1 s  ⇔  Q ≤ R/((h/dt)²·dt) = 7.148e-06` ⇒ 取 `Q_MAX = 7.14e-06`。
- 复核（`mag_pull_design.py`）：**|w| = 0…2000 dps 全段 τ ≥ 1.001 s，2° 误差的修正速度 ≤ 1.999 dps ⇒ 全部满足**。
- 自洽性：满量程漂移 2 dps 下的稳态滞后 = `漂移率 × τ = 2 dps × 1.001 s = 2.0°` = 地磁自身误差 σ_mag
  —— 即"陀螺误差涨到地磁那个量级时，地磁才以刚好能抵消满量程漂移的速度牵引"。
- 全段**没有任何 K 钳位 / 速率钳位**：只改 Q、R、地板，公式全是标准的。

## 8.8 VER=123：地磁→EKF 的**两个入口**（互斥）+ 重力矢量误差估计累加器

用户设计口径（原话要点）：小运动下内部维护一个数（无有效重力牵引按**当前速度**累加、有重力牵引**比例衰减**，
用实测系数拟合：**运动误差 1000 ppm、零漂 2 deg/h**），高于阈值才允许地磁用**现在的矢量方式**，
低于阈值（此时重力矢量误差很低）改为**把地磁矢量投影到以重力为法向量的平面**（= 旧的、当年地磁唯一融合方式），
**只修正姿态角**；两个入口**互斥**；**防溢出**（大于 u32 范围时停在最大值不回绕）；
帧基用 **EKF 观测帧**、门控判断用两帧之间的 **DRDY 降采样**。
脚本：`tools/ekf_session/patch_v123_mag_two_entries.py`。

### 8.8.1 两个入口（互斥，一次只执行一个）

| | 入口 A（旧） | 入口 B（今） |
|---|---|---|
| 观测 | **地磁矢量投影到以重力为法向的平面**，取平面内航向角残差 `r = wrap_pi(thm − thp)`（测量−预测） | 矢量方式：e1 偏航维 + e2 倾斜维，二维 `r2v[0]/r2v[1]` |
| H | **只有偏航行** `s_H[0][8] = 1` | H[0]=e1 行、H[1]=e2 行（三姿态行） |
| 注入掩码 | **`0x0100`（只开偏航状态；roll/pitch 的 K 被清零）= 只修正姿态角** | `0x01C0`（6/7/8 三行） |
| R | `σ_h² + (tanI·σ_tilt)²`，σ_h=2°、σ_tilt=√(P66+P77) 上限 5°（重力有效时自动退化成 ≈(2°)²） | `diag((2°)²,(3°)²)`（VER=118 起固定） |
| 源码来源 | `bak_src/V5F/User/src/proc_ekf.c.bak_v103_magvec`（VER=103 之前，当年**地磁唯一融合方式**，实机验证过符号） | VER=103 起的现实现，**一字未改** |
| 何时启用 | `s_grav_err ≤ THR`（重力矢量误差很低） | `s_grav_err > THR`（重力长期没牵引、倾角只能靠陀螺） |

两者前置校验共用（`|m|` 范围、`mag_norm` 门、DRDY 时刻对齐/转动补偿、`s_mag_r > R_MAX` 剔除、IST 采样去重）；
被拦下时**两个都不执行**（另一个也不补偿）——互斥语义。

### 8.8.2 累加器 = 重力矢量（倾角）误差估计（u32 定点，单位 1e-6 deg）

**帧基 = EKF 观测帧**（实测周期 = 16 帧传播 + 7 帧观测 = **23 DRDY 帧 ⇒ 8021.9/23 = 348.8 Hz**；
`v5f_tune.h` 里"DECIM=16 → 501.4 Hz"的旧注释是错的，已在本节更正）。
**门控判断 = 两观测帧之间 23 个 DRDY 帧的降采样**：多数（`2·ok ≥ n`）算"有重力牵引"。

```c
/* 每个 DRDY 帧 */                s_ff_n++;  if (gate->ekf_tilt) s_ff_ok++;
/* 每个 EKF 观测帧（stage 16）*/   多数有牵引: s_grav_err -= s_grav_err >> V5F_EKF_MAG_FF_SHIFT;
                                  否则:      inc = (1000ppm*|w|_dps + 2deg/h) * dt * 1e6  [µdeg]
                                             s_grav_err += inc（饱和，到顶停住不回绕）
```

| 参数 | 值 | 依据 |
|---|---|---|
| `V5F_EKF_MAG_FF_SHIFT` | **7** | 衰减 ×(1−1/128)/帧 ⇒ τ=128 帧=**0.367 s**，与重力通道自己的倾角收敛 `τ=dt/(K·h)≈0.36 s` 一致 |
| `V5F_EKF_MAG_FF_THR_DEG` | **2.0°** | 地磁自身误差量级（S3 实测 p50 1.7~2.15°）；与 §8.7 偏航口径同源 |
| `V5F_EKF_GYRO_DRIFT_DPS` | **2/3600 °/s** | 用户口径：零漂 2 deg/h |
| `V5F_EKF_GYRO_KS_YAW` | 1000 ppm | 用户口径：满量程 1000 ppm（§8.7 已引入） |
| `V5F_EKF_MAG_FF_MAX` | `0xFFFFFFFFu` | 饱和上限 = 4294.97°，**不回绕** |

**分辨率与增量**（dt=2.867 ms/观测帧）：

| \|w\| dps | 0（纯零漂） | 20 | 100 | 300 | 1000 |
|---|---|---|---|---|---|
| 增量 (µdeg/帧) | **1.59**（定点不截断） | 58.9 | 288 | 862 | 2870 |
| 到 2° 用时 | 1.0 h | 97 s | **19.9 s** | **6.6 s** | 2.0 s |

⇒ **静止/小运动永远停在入口 A**（重力一直有效，累加器被衰减到 0）；**持续机动几秒~几十秒自动切入口 B** ✓。

**不加回差**（用户确认）：判据**不含 EKF 的 P 反馈**（只由 `|w|` 与重力门驱动），单帧增量 ~300 µdeg 对阈值 2e6 µdeg
是 1/7000，穿越缓慢单调 ⇒ 不存在"更新→P 变→判据翻"的极限环。
