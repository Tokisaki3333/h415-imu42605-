# 地磁标定录制协议（VER=101 调试流）· 数据充分性核对

目标：把"地磁牵引随姿态变化"这条误差通道压掉。数学上剩下的只有物理耦合
`∂ψ/∂倾角 = tan(dip) = 2.08`（见 `mag_observability_math.md`），其余都是标定误差。

---

## 1. CDC 调试流够不够（逐列核对）

调试帧 = 162 × float32（654 B/帧，抽帧 24 → ≈337 Hz）。用
`python tools/calib/cols_162.py` 自检列号（锚点全部命中才继续）。

| 用途 | 列（0 基） | 有？ |
|---|---|---|
| **真值姿态** att.q（旧链，**不含地磁**：`proc_attitude.c` 里 mag 引用 = 0） | 0–3 | ✅ |
| **原始地磁 LSB**（标定输入，未标定） | 38–40 | ✅ |
| IST8310 样本序号（判"新样本沿"，磁 ~190 Hz vs 帧 337 Hz，约 50% 帧是新值） | 41 | ✅ |
| 现用标定输出 mag.f（归一化方向）/ mag_norm（归一化前模长 = 标定质量独立读数） | 42–44 / 45 | ✅ |
| 角速率（选样 + 软权 `1/(1+(ω/20dps)²)`）gyro_dps / gyro_lsb | 26–28 / 18–20 | ✅ |
| 比力（选 \|a\|≈1 g，剔除非静态）accel_g / accel_lsb | 32–34 / 21–23 | ✅ |
| 健康位 flags（bit2 = att.valid）、att_tilt 门、is_static | 16 / 36 / 8 | ✅ |
| 温度（零偏/标定漂移解释变量） | 24 | ✅ |
| 帧间隔 dt(us)、绝对 tick | 25 / 159,160 | ✅ |
| **版本指纹 fw_tag** = (VER<<16)\|(162<<8)\|flags，VER=101 时为 6660615 | 76 | ✅ |
| 逐帧校验和（XOR 前 644 B，落在第 161 列） | 161 | ✅ |

**结论：标定所需的量一个不缺。** 两点限制要知道：

1. 帧里只有 **IST8310 样本序号**，没有磁样本的独立时间戳 ⇒ 磁与姿态的配准精度受限于
   上报栅格（1/337 s ≈ 3 ms）。在 |ω| = 50 dps 下对应 0.15° 的姿态错配 ——
   **所以要求慢转（建议 25~50 dps）或"转一段-停一下"**，工具用 `--wmax` 直接把这些样本剔掉。
2. 旧链 att.q 没有绝对方位参考（无地磁）。拟合里**常数偏航偏置会被 w0 吸收**，不影响 A/C；
   慢漂移由已跟踪的陀螺零偏压住（残余 ~1.23 deg/h 量级），单次录制控制在 1~2 min 内即可忽略。

## 2. 录制动作：**平面 360 不够**（有证明）

9 参数 `y = A·raw + C` 的"姿态辅助"拟合要求 `R_i·y_i ≈ w0`。用合成数据自检的结果
（`python tools/calib/selftest_mag360.py`）：

| 动作 | 设计矩阵零空间维数 | 半分一致性 ‖A1−A2‖/‖A‖ | 结果 |
|---|---|---|---|
| 全球面（多轴各整圈） | **1**（只剩标度自由度） | 0.000 ~ 0.001 | ✅ 9 参数可辨识 |
| 纯水平偏航 360°（转多少圈都行） | **6** | **1.71** | ❌ 竖直/出平面项完全没被激励 |

原因：绕竖直轴转，机体系磁场只在一个圆锥面上扫，**竖直分量恒定** ⇒ A 的 z 行与 C 的竖直项
不可观测；而"标定误差随姿态混进航向"恰恰主要来自这些未定项。所以必须**激励倾斜**。

### 推荐动作序列（每条 30~60 s，慢速 25~50 dps，中间不要碰机械）

1. **静态锚点**：水平静置 10 s；±30°/±60° 俯仰、±30°/±60° 横滚各停 5~10 s（给拟合提供低速率点）。
2. **三轴整圈**：绕 x / y / z 各慢转 ≥ 360°（可正反各一次）。
3. **倾斜锥**：保持俯仰或横滚 ≈45°，绕竖直慢转 360°。
4. **完全翻转**：翻过来（≈180°）重复第 2 步的至少两个轴 —— 这一步决定竖直项能不能解出来。

环境：离机架/电机/磁铁 ≥ 2 m，桌面无铁磁物，标定后**不要改动机械安装**（改动 = 重标）。

## 3. 串口录制（仓库自带 `tools/calib/rec.py`）

```bash
python tools/calib/rec.py --list                     # 列串口（WCH-Link 那个不是 IMU 口）
python tools/calib/rec.py --selftest                 # 无硬件自检：合成流->解析->文本回读
python tools/calib/rec.py -p COM5 -t 90 --seg        # 录 90 s，按上面的动作协议分段提示
python tools/calib/rec.py -p COM5 -t 60 --bin raw.bin   # 同时落 648 B/帧 纯 payload 二进制
```

- 输出默认 `serial_runtime_<时间戳>_export.txt`，与历史录像**逐字节同格式**
  （`=== Serial logging started ... ===` + `[HH:MM:SS.mmm] [RX] A5 5A ... 5A A5`），
  所以 `mag360_cal.py`、`jf_load.py`、以及全部旧分析脚本直接可用。
- 录制中逐帧校验：帧头/长度/帧尾、`|att.q|≈1`、`dt_us`、**`fw_tag`（从源码现算，不写死）**、
  逐帧校验和；每 20 s 报一次 好帧/坏帧/丢字节/Hz/校验和通过率，结束给判定。
- `--seg` 会把每段动作写成 `# ==== [t s] 第 k/N 段 ... ====` 注释行进日志（分析时可切段）。
- 6 s 内解析不出 `A5 5A` 帧时，脚本会明确提示：固件还是**验收模式**（20 B JustFloat 无帧头）⇒
  要么用 `tools/calib/cap.py`（认帧尾 `00 00 80 7F`，带自动重连+按帧分频二进制落盘），
  要么把 `V5F_CDC_QUAT_ONLY` 改回 `0u` 重编。
- 历史遗留：`tools/ekf_session/recv_v9.py`（A5 5A + 二进制 `R:\raw_v9.bin` + 下行命令闭环）
  是 VER=9/83ch 时代的，列号虽仍对（fw_tag=76, dt=25, cmd_*=77..79），但默认路径与假设过时，不建议用来录标定数据。

然后一键标定：

```bash
python tools/calib/mag360_cal.py serial_runtime_XXXX_export.txt
# 可选: --wmax 40 --amag 0.02 --static-only --out my.magcal.txt
```

## 3b. 一键标定

工具做的事与判据：

1. **帧自检**：`fw_tag`（CH=162、VER≥101）+ 逐帧校验和通过率 >99%；两种落盘格式（带
   `A5 5A` 帧 / 纯 payload 流）都能自动定相位。
2. **选样**：att.q 单位化、`flags` bit2 有效、`ist_cnt` 变化沿（新磁样本）、`|a|` 在 1 g ±2%、
   `|ω| < wmax`。
3. **秩判据（硬指标）**：未归一化设计矩阵的 SVD，`σ_i < 1e-4·σ0` 的个数 = 零空间维数，
   **必须 = 1**（纯标度自由度）。>1 就打印未激励方向的能量分布。
4. **半分一致性**：前后半各自独立拟合，`‖A1−A2‖/‖A‖ < 0.15` 且交叉残差小才算稳。
5. **姿态激励范围**：roll/pitch 跨度都 <25° 直接判"只转了平面 360"。
6. **输出**：现用标定 vs 本次拟合的世界系方向残差 p50/p90、`|y|−1` 分布、拟合出的 `w0`
   （应与 dip/decl 模型 `[-0.0567 0.4308 -0.9008]` 同向），以及可直接粘贴的
   `V5F_MAG_A_INIT` / `V5F_MAG_C_INIT`。

## 4. 写回固件 + 回归验收

1. 把生成的 4 行宏粘到 `V5F/User/inc/v5f_tune.h` 的 `V5F_MAG_A_INIT` / `V5F_MAG_C_INIT`
   （GBK 文件，用 `tools/ekf_session/` 里的字节级补丁脚本改，别用 UTF-8 编辑器直接存）。
   `V5F_MAG_CAL_EN` 保持 1；A 只在 `SPI_rx.c` 实体化一次，不用动别处。
2. 建议 **bump `V5F_FW_VER`**（标定值变了就 bump；`fw_tag` 会随之变化，工具对 VER 只要求 ≥101）。
3. 回归验收（都用调试流就能算，`mag360_cal.py` 已给前 4 项）：
   - `|‖A·raw+C‖ − 1|` 中位 < 1%（列 45 的 `mag_norm`）；
   - 世界系方向残差 p90 < 1.5°（静点应 < 0.5°）；
   - `mag_cmp_thm − mag_cmp_thp`（列 144/145）随 roll/pitch 的回归斜率应无可辨识趋势；
   - 偏航残差 vs 倾角的斜率应 ≈ `tan(dip) = 2.08`（标定差会让它偏离且随姿态系统漂）；
   - 全姿态 360° 闭合：绕任意轴转 360° 回原点，偏航残差与 roll/pitch 的相关性 ≈ 0。
