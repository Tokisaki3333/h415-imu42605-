# 地磁在 EKF 里的可观测性：怎么把"绕磁力线的旋转无观测"写成结构性质

问题：如何设计 EKF 数学，才能**显式**表明"绕磁北矢量的旋转无有效观测"——就像重力观测天然不能修正偏航？

---

## 1. 先把两个传感器写成同构的"方向观测"

设体坐标系下的姿态估计 `R̂`（体→世界），世界系参考矢量 `v̂_n`（重力 `ê_z` 或磁场 `b̂_n`），
体坐标系下的测量单位矢量 `m̂_b`（比力方向 / 已标定磁场方向）。

预测的体坐标系方向：`v̂_b(q) = R̂ᵀ v̂_n`。
用**体坐标系扰动** `R_true = R̂·Exp(δθ)`，一阶展开：

```
v̂_b,true = Exp(−δθ)·v̂_b ≈ v̂_b − δθ × v̂_b = v̂_b + [v̂_b]× δθ
⇒ ∂v̂_b/∂δθ = [v̂_b]×            （[·]× 为反对称阵）
```

**2 维残差**（去掉沿参考方向的不可观测分量，这就是"方向观测"的标准写法）：

```
r = (I − v̂_b v̂_bᵀ)(m̂_b − v̂_b)
H = ∂r/∂δθ = (I − v̂_b v̂_bᵀ)·[v̂_b]×          (3×3, rank = 2)
```

**结构零空间（本文的核心结论）**：

```
H · v̂_b = (I − v̂_b v̂_bᵀ)·([v̂_b]× v̂_b) = (I − v̂_b v̂_bᵀ)·0 = 0      ← 精确成立，不是近似
```

即 `N(H) = span(v̂_b)`，**且与测量值、与标定好坏无关**。对照两种情况：

| 传感器 | 参考矢量 `v̂_n` | Jacobian | 零空间（不可观测方向） | 物理说法 |
|---|---|---|---|---|
| 加速度计 | `ê_z`（重力） | `H_g = (I − ĝ_b ĝ_bᵀ)[ĝ_b]×` | `span(ĝ_b)` | **绕重力（=偏航）不可观测** ⇒ 重力不该、也不能修偏航 |
| 地磁 | `b̂_n`（磁力线） | `H_m = (I − b̂_b b̂_bᵀ)[b̂_b]×` | `span(b̂_b)` | **绕磁力线不可观测**（不是绕世界竖直！） |

注意两处容易混淆的地方：

1. 地磁盲的是**磁力线** `b̂_b`（磁北再按磁倾角下倾 I≈64.3°），**不是**水平磁北方向，也不是世界竖直。
2. 重力盲的是 `ĝ_b`。两者**不平行**（夹角 = 90°+I），所以

```
[H_g ; H_m]  满秩  ⟺  ĝ_b ∦ b̂_b，其条件数由 |ĝ_b × b̂_b| = cos(I) ≈ 0.43 决定
```

**偏航之所以可观测，恰恰是靠"重力看不见的那一维由地磁补上"**；任何单个传感器都缺一维。
本地 dip=64.3° ⇒ `cos(I)=0.43`，也就是偏航信息只有水平分量的 43%，
噪声/误差放大 `1/cos(I)=2.30`；而**倾角误差混进偏航**的斜率是

```
∂ψ/∂δθ_east = tan(I) = 2.08        ← 与现有常数 V5F_EKF_DIP_TAN = 2.08 一致
∂ψ/∂δθ_yaw  = 1
```

这解释了 `proc_ekf.c` 里 R 的写法 `R² = R0² + (dip_tan·σ_tilt)²`：倾角不确定度按 `tan(I)` 混入偏航新息。

## 2. 现有实现处于哪一档（对照）

- **重力侧已经是"显式"写法**：`ekf_m6`（`proc_ekf.c` L476-507）
  `p = Rᵀê_z`、`r = (I − ppᵀ)(f̂ − p)`、`H = (I − ppᵀ)M` ⇒ `H·p = 0`。
  绕重力不可观测是**结构**保证的，"重力不修偏航"不需要靠门控去压。✅
- **地磁侧是标量形式**：`ekf_m7_mag`（L638+）只有 1 维残差 `r[0]`（
  用 dip/decl 固定参考 `b0=(ci·sin δ, ci·cos δ, −dip_tan·ci)` + 陀螺把磁样本推到当前时刻）。
  标量观测的零空间是**平面（2 维）**，其中含 `b̂_b`，但"绕 b̂ 不可观测"这句话**说不清楚**——
  这就是"要显式化"的动机。并且它的 R 用一个各向同性的放大项把 `tan(I)·σ_tilt` 折算进去，
  属于"承认耦合"而不是"结构解耦"。

## 3. 三种可选数学形式（按"显式程度/改动量"排）

### A. rank-2 对称式（最显式，和重力完全同构）
```
r = (I − b̂_b b̂_bᵀ)(m̂_b − b̂_b)          b̂_b = R̂ᵀ b̂_n
H = (I − b̂_b b̂_bᵀ)[b̂_b]×                 H·b̂_b ≡ 0
```
- 优点：零空间可证、与重力同构，代码结构可以复用同一套 `(I − ppᵀ)` 机制；
- 代价：地磁同时修正 roll/pitch（与重力**信息重复**）。标定不好时两者互相拉扯——
  平面标定下不建议这样开。

### B. rank-1 互补式（推荐：分工显式，且只用平面标定也稳）
让地磁**只做重力做不了的那一维**：
```
Π_g = ĝ_b ĝ_bᵀ                      （体坐标系"竖直"方向的投影，即偏航方向）
H_m^yaw = Π_g · H_m                  rank = 1
H_g     = (I − ĝ_b ĝ_bᵀ)[ĝ_b]×       rank = 2
rank(H_g) + rank(H_m^yaw) = 3  ⇒ 显式分工：roll/pitch 归重力，yaw 归地磁
```
- `H_m^yaw·b̂_b = Π_g·(H_m b̂_b) = 0` 仍成立 ⇒ "绕磁力线不可观测"照样是结构性质；
- 地磁不再触碰 roll/pitch ⇒ 与"只做过平面 360 标定、竖直信息不可信"的现状**一致**；
- 这是把"重力禁止修偏航"对称化后的自然结果：**重力只在 ⊥ĝ 平面内做功，地磁只在 ∥ĝ 方向做功**。

### C. 标量偏航 + 显式解耦项（改动最小，等于给现在的 M7 补上解耦）
```
r_yaw = (ψ_meas − ψ_pred) − (∂ψ/∂tilt)·δθ̂_tilt      （Schmidt/consider 式解耦）
∂ψ/∂δθ_east = tan(I) = 2.08,   ∂ψ/∂δθ_yaw = 1
```
- 把"倾角能解释的部分"先扣掉，只把**重力看不见的那一维**交给地磁；
- 必须把**扣掉的量**一并记录（否则等于把耦合藏起来了）。

## 4. 怎么在固件/日志里"显示地表明"（可验证，而不是靠嘴说）

1. **结构自检**（和现有 `p_p_zz`/`prop_ok` 自检同风格，逐帧或抽帧算）：
   - `n_b = ‖H_m·b̂_b‖`（应 ≈ 0）、`n_g = ‖H_g·ĝ_b‖`（应 ≈ 0）
   - `s = |ĝ_b × b̂_b|`（≈cos(I)=0.43；决定联合可观测性与条件数）
   - 信息矩阵 `F = Σ Hᵢᵀ Rᵢ⁻¹ Hᵢ` 的 3×3 特征分解：`λ_min` 与其特征向量 `v̂_min`
     —— 只开重力时 `v̂_min = ĝ_b`，只开地磁时 `v̂_min = b̂_b`，两者都开时无零特征值。
   - 每次更新的"零空间泄漏" `‖(δθ_applied·v̂_min) v̂_min‖`（应 ≈0）。
2. **离线验证（不需要改固件）**：162 通道调试帧里已经有 `mag.f`（体坐标系已标定磁场 ⇒ `b̂_b` 的测量）、
   `accel_g`（⇒ `ĝ_b` 的测量）、`ekf.q`、`mag_r_deg`、`mag_dq{x,y,z}`、`nis[4]`。
   用这些就能重建 `H_m`/`H_g`，数值验证上面几条恒等式，并回归出
   "倾角误差 → 偏航新息"的斜率是否 = `tan(I) = 2.08`。
3. 若要把 `λ_min/v̂_min` 直接画出来：最省的做法是把 `|ĝ×b̂|` 与 `λ_min` 加进**抽帧后**的调试帧，
   不要在 8 kHz 里做特征分解（放到 1/24 抽帧那一帧算即可）。

## 5. 对"下一步地磁 360 标定"的直接含义

- 平面 360 标定只约束了水平面：A 的竖直行/列与 C 的竖直项（以及出平面的交叉轴项）没被约束住。
  而上面的数学说明：**竖直/出平面误差会按 `sin(倾角)`/`tan(I)` 的几何混进航向通道**，
  表现为"牵引量随姿态变化"——这正是"地磁牵引与姿态误差放大"的耦合来源之一。
- 3D 椭球标定（A 的 9 项 + C 的 3 项，可对称化）把这个耦合通道压掉，剩下的
  `∂ψ/∂tilt = tan(I)` 是**物理**耦合，只能靠 R / 解耦项处理。
- 标定后的验收判据（都用现有/计划中的日志列）：
  1. `|‖A·raw + C‖ − 1|` 分布（`mag_norm` 列）：目标 <1~2%；
  2. `H_m b̂ ≈ 0` 的结构残差（上面第 4 节）；
  3. `mag_cmp_thm`（实测航向）− `mag_cmp_thp`（预测航向）随 roll/pitch 的回归斜率应无可辨识趋势；
  4. 偏航残差 vs 倾角的回归斜率应 ≈ `tan(I)=2.08`（标定差会让它偏离且随姿态系统性漂）；
  5. 全姿态 360 闭合：绕任意轴转 360° 回原点，偏航残差与 roll/pitch 的相关性 ≈ 0。

---

## 6. 一句话总结

把地磁写成**方向观测**（`r=(I−b̂b̂ᵀ)(…)`、`H=(I−b̂b̂ᵀ)[b̂]×`）时，
"绕磁力线的旋转无观测"就是 `H·b̂ ≡ 0` 这条**结构恒等式**，和"重力不能修偏航"（`H_g·ĝ ≡ 0`）完全同构；
工程上再补两份东西——(a) `H_m` 只保留 `Π_g = ĝĝᵀ` 这一维（分工显式），
(b) 把 `‖H·v̂‖`、`|ĝ×b̂|`、信息矩阵 `λ_min/v̂_min` 打进日志（可验证）。

## 7. 实现记录：VER=103 已按方案 A 落地（真牵引）

`V5F_EKF_MAG_MODE = 1u`（0u 为旧标量牵引，回退用）。代码在 `proc_ekf.c: ekf_m7_mag()`。

**数学形式（实际写进固件的那份）**

```
b̂_b = R(q̂)ᵀ · b̂_n                    预测的机体系磁场方向
r    = P_⊥ m̂ = m̂ − (m̂·b̂_b) b̂_b         2 维残差（⊥b̂ 平面内；不做姿态投影）
e1   = normalize(ẑ × b̂_b),  e2 = b̂_b × e1     ⊥b̂_b 的正交基
H    = −c1 · e_iᵀ [b̂_b]× R̂ᵀ            i=1,2；c1 = m̂·b̂_b
更新  ekf_update(R=σ²I₂, m=2, r2, …, inj_mask=0x01C0)   ← 作用在旋转矢量 dx[6..8]
```

三个容易踩的坑（都由 `tools/ekf_session/check_v103_magvec.py` 的有限差分检查抓出来并修正）：

1. **扰动约定**：本固件的姿态扰动是**世界系**的（`ekf_inject`: `q ← dq ⊗ q`；M6 的 `Rᵀ[up]×` 同理），
   所以 H 必须带 `R̂ᵀ`，结构零空间方向是**世界系磁场方向** `b̂_n`（`H·b̂_n ≡ 0`）。
   按体坐标系写成 `−e_iᵀ[b̂]×`（零空间 `b̂_b`）会差一个 `R̂ᵀ`——方向全错。
2. **残差写法**：`P_⊥m̂ = m̂ − (m̂·b̂)b̂`；写成 `(m̂−b̂) − (m̂·b̂)b̂` 会多减一个 `b̂`。
   虽然再投影到 `⊥b̂` 后数值被消掉，但 H 就不再是它的 Jacobian（差分差 7.5e-4）。
3. **H 里的 `c1`**：`c1 = m̂·b̂ ≈ 1` 也要乘进去，否则同样破坏自洽（≈ 1% 残差时差 1.5e-4）。

**参数与门控（VER=103 的取舍）**

- `R = σ² I₂`，`σ = V5F_EKF_MAG_VEC_SIG_DEG = 0.9°` —— 取自本机实测方向误差（p50 0.5°/p90 1.3°，
  见 `mag360_recording_protocol.md` §6）；**不再**用 `R² = R0² + (tan(dip)·σ_tilt)²` 的人为放大。
- `V5F_EKF_MAG_VEC_K_MAX = 0.10`：单次更新步长 = `K·|r|` 的硬上限（防磁样本把姿态猛拽）。
- **取消"运动中禁磁"**：删掉原 `V5F_EKF_MAG_GT_HOLD_S` 那条 hold 与 `s_mag_tilt_bad_s`。
  那条是为"姿态误差 → 重力法平面投影误差 → 地磁误差"设的，是**投影式**观测的产物；
  真牵引在机体系做差没有这个耦合。合法性只看**模**：
  外门 `gate->ekf_mag_yaw = (|mag_norm − 1| < V5F_MAG_ERR_LIM)`，另有残差上限 `R_MAX` 与
  "同一磁样本不重复更新"（磁 ~166–190 Hz vs 帧 ~335 Hz）。

**验证（本机无 C 编译器，改用数学等价 + C 结构检查，全部通过）**

| 检查 | 结果 |
|---|---|
| `e1,e2` 正交且 ⊥ `b̂_b` | 3.3e-16 |
| `\|H·b̂_n\|`（结构零空间 / 绕世界磁场轴无观测） | 3.0e-16 |
| `H` vs 中心差分 Jacobian（世界系扰动、冻结基） | 7.7e-10 |
| 姿态绕 `b̂_n` 旋转 → 残差不变 | 6.2e-10 /rad |
| 完美量测下 `\|r2v\|` | 9.2e-17 |
| 去注释后括号平衡 / `#if-#endif` 配对 / 无禁磁残留 / tune 常量 | 全部 OK |
