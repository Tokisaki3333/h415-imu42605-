# EKF 设计终审：正确性 / 可解性 / 闭合性

对 `ekf_design.md` 的逐条复核。分三级：**严重**（会直接导致失败）、**中等**（限制性能或必须写明）、**澄清**。
每条给"症状 → 证据 → 修法"。

---

## 一、严重缺陷（3 条，都会导致失败）

### ★S1. `b_dop` 与 ZUPT 门构成闭环 —— 上电即死锁

**症状**：上电后 ZUPT 门永不开，`b_dop` 永不更新，M5 永不生效。

**证据**（把设计里的依赖链画出来）：
```
b_dop ──→ v_gps_corr = v_gps − b_dop ──→ 门 |v_gps_corr| < 0.3 ──→ ekf_zupt ──→ b_dop 牵引
   ↑                                                                              │
   └──────────────────────────────────────────────────────────────────────────────┘
```
初值 `b_dop = 0`。实测静止时**原始**多普勒速度均值 **+0.25~0.55 m/s**（234804 是 +0.346，
235508 是 +0.544）。于是 `|v_gps_corr| ≈ 0.35 > 0.3` ⇒ 门关 ⇒ `b_dop` 不动 ⇒ 门永久关。
**这与 233341 那个"证据→阈值→is_static→证据"的自环是同一类错误**，我竟然又犯了一次。

**修法**：门只允许依赖**外生量**，不许依赖被估计的量。

```
ekf_zupt 门  = is_static
             ∧ (|a_lin| < 0.05 g)
             ∧ (speed_lp < V5F_DOP_GATE_MPS)        ← speed_lp = 原始多普勒速度的 1 s 低通
```
- **用原始（未扣偏置）速度**，环路断开：门 → b_dop（单向）。
- **阈值取 0.8 m/s**：实测偏置上限 0.55（瞬时尖峰 1.47），走动 >1 m/s ⇒ 两边都有余量。
- **必须低通**：原始速度在静止时有到 1.47 m/s 的尖峰，直接用会让门抖动；
  1 s 低通后静止 ≈ 偏置（0.25~0.55，稳定），走动 ≈ 步速。
- M4（GPS 速度观测）门用**互补条件** `speed_lp > 0.8`，保证静止/运动不重叠。
  M4 的量测值仍用 `v_gps − b_dop`。

### ★S2. M6 是**单位矢量**观测，本质只有 2 个自由度 —— 用 3 维会灌入虚假信息

**症状**：姿态的"模长方向"被当成可观测量，与加计零偏估计互相打架，倾角反而变差。

**证据**：静止时比力 f_b = −R(q)ᵀg_n（g_n = (0,0,−9.80665)），故 `f̂_b = R(q)ᵀê_z` = 机体系"上"方向（单位矢量）。
线性化（全局误差 `q_t = Exp(δθ)⊗q̂` ⇒ `R(q_t)ᵀ = R(q̂)ᵀ(I − [δθ]×)`）：
```
h(x_t) = R(q̂)ᵀ(I − [δθ]×)ê_z = h(x̂) − R(q̂)ᵀ(δθ × ê_z) = h(x̂) + R(q̂)ᵀ(ê_z × δθ)
⇒  H_δθ = R(q̂)ᵀ [ê_z]×                     (3x3)
```
**`[ê_z]×` 的秩是 2**，零空间正是 **ê_z（偏航方向）**。
这一个式子同时证明了两件事：
1. 重力观测恰好只能定 2 个姿态自由度（倾角）—— 与设计里"偏航由磁力计负责"完全自洽；
2. 它天然**降秩**，所以 3 维残差 + `σ²I` 是错的：那个径向分量没有对应的物理自由度。

**修法**：把残差与雅可比都**投影到切平面**：
```
r ← (I − f̂_b f̂_bᵀ) · (z − h(x̂))
H ← (I − f̂_b f̂_bᵀ) · H
R  = σ_tilt² · I          (投影后有效秩 2，投影矩阵自带降秩)
```
效果：径向（模长）分量自动不进更新，且 `S = H P Hᵀ + R` 保持满秩可逆。

### ★S3. 不可观测方向必须**按门动态投影** —— 不能永久投影，也不能不投影

**背景**：我第一版把偏航永久投影（`K[8,:]=0`），你纠正后我**整个删掉了投影**。两次都错。

**症状（现在的版本）**：当 M7（磁偏航）门关时，偏航不可观测，但 M1/M2/M4/M5 的更新仍然会通过
`P` 的交叉项把 `P[8][8]` **虚假压低**。滤波器会"以为"偏航变准了，等磁力计恢复后再用这个
被低估的协方差去融合 → 磁力计的异常读数被过度信任。这是经典的 EKF 不可观测方向不一致性
（OC-EKF 要解决的问题）。

**修法**：按"哪些姿态参考门开着"决定投影：

| M6 倾角门 | M7 偏航门 | 姿态可观测 | 处置 |
|---|---|---|---|
| 开 | 开 | 3 维全可观测 | 不投影 |
| 开 | 关 | 2 维（倾角） | 投影掉 `δθ_z`（K 的第 8 行置零） |
| 关 | 开 | 1 维（偏航） | 投影掉倾角 2 维 |
| 关 | 关 | 0 维 | 投影掉整个姿态块（第 6~8 行置零） |

实现：把 H 的姿态列（6,7,8）在更新前按上表投影掉，等价于在 K 上做。**一行 3 个 `if`**。

★ 同样的道理适用于 `δbg`：姿态参考全关时陀螺零偏增量不可观测，此时 `Q_bg` 必须≈0，
否则零偏协方差会在无参考期间无限涨。

## 二、中等（必须写明，否则会调不出性能）

### M1. 加计零偏的水平分量在**静止时与倾角不可分**

静止时水平方向的比力残差 = 水平加计零偏 + 倾角误差引起重力投影，两者产生**同一个观测量**。
这是经典的 accel-bias / tilt 歧义。

| 分量 | 何时可观测 | 处置 |
|---|---|---|
| `δba_z` | **静止即可**（ZUPT 下竖直比力 = g + ba_z） | 正常估 |
| `δba_x, δba_y` | **只在有运动激励时**（速度变化把两者分开） | `Q_ba_h` 必须≈0，否则不可观测方向随机游走 |

⇒ J 组里 `σ_ba_rw` 要**逐轴分别给**：垂直轴可以给一点（有观测），水平两轴给 0 或极小。

### M2. `b_baro` 只靠 M2（GPS 高度）可观测

气压单独只能观测 `p_z + b_baro` 这一个组合。分开它们必须靠 GPS 高度（R = 5.5 m，很弱但唯一）。
⇒ **GPS 高度门关时（无定位/VDOP 差）必须把 `Q_baro` 置 0**，此时气压只当"相对高度"用，
绝对高度会缓慢漂 —— 这是物理限制，不是 bug，但要写进文档与自检。

### M3. 单位陷阱：`δbg` 与 M7 的 H

- 设计里 `δbg` 写的是 **dps**，而 `δθ' = −R δbg` 要求 `δbg` 是 **rad/s**。
  若坚持存 dps，F 里必须带 `57.29578`；**建议内部一律 rad/s，只在上报时转 dps**。
- M7：`z = D` 是**度**，`δθ` 是 **rad** ⇒ `H = −57.29578` **deg/rad**，
  `R = V5F_MAG_YAW_R_DEG² = 0.49` **deg²**，`S` 才是 deg²。三者的单位必须一致声明。
  （更干净：内部全用 rad，`R = (0.7/57.29578)²`。）

### M4. M3 的 `|Δh| < 50 m/步` 必须对**气压自己的历史**判

若拿它和 EKF 的 `p_z` 比，门就依赖滤波器输出 —— 又一个自环。
必须是"本拍气压高度 − 上拍气压高度"，纯外生。

### M5. 两个层次的门要分清并都记录

- **外部门控**（你的铁律）：门阶段（第 8 步）用**外生量**算，第 7 步下一帧读，写入 `ekf_gate_bits`。
- **内层新息 χ²**：更新时刻用残差自算（`rᵀS⁻¹r < χ²`），是**逐次更新的接受判据**，
  与外部闸门不是一回事，也需要单独留痕（例如 `gate_bits` 的 bit9 记"本帧被 χ² 剔除"）。

设计文档把两者混着写了，要拆开。

## 三、澄清（不改语义，但必须钉死）

### C1. 气压观测的符号

设计 §3 M3 写的是 `z = h_baro = −p_z + b_baro`，与 §1.1 的"`p_z` 向上为正"矛盾。
**钉死为**：`p_z` 向上为正、`h_baro` 随高度增大 ⇒ `z = p_z + b_baro`，
`H` 对 `δp_z` 与 `δb_baro` 都是 `+1`。初始化 `b_baro = h_baro(0)`（使 `p_z(0)=0`）。

### C2. float32 下 `P` 的正定性

`P = P − K S Kᵀ` 长跑会因舍入失去正定性（尤其 `S` 条件数大时）。
**处置**：每步对称化 `P ← (P+Pᵀ)/2`（已在设计里）+ 对角下限（`P_ii ≥ 1e-12`）；
姿态/位置更新建议用 Joseph 形式 `P = (I−KH)P(I−KH)ᵀ + KRKᵀ`。

### C3. 原需求里的"合加速度大小（标准单位）"在输出清单里没有显式出现

你最初要的两个输出是「重力系世界四元数姿态」和「合加速度大小（全用标准单位）」。
前者有（`ekf.q`），后者**没有直接列**：报表里的 `a_lin` 与 `accel_g` 都是 **g**。
**处置**：要么加 `ekf.a_nav[3]`（导航系线性加速度，**m/s²**，3 列），
要么在文档里明确"由 `a_lin × 9.80665` 覆盖"。建议前者 —— 它才是"标准单位"的那个量。

## 四、可观测性总表（回答"维度是否可解"）

16 个状态，可观测性**依赖门**，没有一个是无条件可观测的：

| 状态 | 维 | 观测来源 | 可观测条件 | 不可观测时 |
|---|---|---|---|---|
| `δp` | 3 | M1(2) + M2(1) | GPS 定位 | 纯 IMU 积分，按 Q 涨 |
| `δv` | 3 | M4(2) + M5(3) + `δp` 耦合 | M4 或 M5 门开 | 只积分，误差按 `ba` 不确定性涨 |
| `δθ` 倾角 | 2 | M6(2) | 门B 开 | **投影掉**（S3） |
| `δθ` 偏航 | 1 | M7(1) | mag 门开 | **投影掉**（S3） |
| `δba_z` | 1 | M5 | 静止 | 与倾角歧义（M1） |
| `δba_xy` | 2 | **仅运动激励** | 有加速度 | `Q≈0`，否则随机游走 |
| `δbg` | 3 | 经 `δθ` + 姿态参考 | 至少一个参考门开 | `Q_bg≈0` |
| `δb_baro` | 1 | M2 | GPS 高度门开 | `Q_baro=0`，只做相对高度 |

**结论**：**维度是可解的，但不是无条件可解** —— 必须靠"按门动态投影"（S3）来保证
"不可观测时协方差不被虚假压低"。这正是 S3 为什么是严重缺陷而不是优化项。

**自由度自洽性核对**（这一项通过）：
- 姿态 3 维 = M6 的 2 + M7 的 1 ✓（由 H 的秩严格给出，见 S2）
- 速度 3 维 = M4 的 2（水平）+ ZUPT 的 3（含竖直）✓
- 高度 2 个未知（`p_z`, `b_baro`）= M2 + M3 两个观测 ✓，但条件数差，依赖 M2
- 加计零偏 3 维：竖直 1 维静止可观测，水平 2 维需运动 ✓（已写明限制）

## 五、闭合性核对（回答"是否闭合"）

| 检查项 | 结果 |
|---|---|
| 门是否只依赖外生量 | **S1 之前不通过**（`b_dop` 自环）；修后通过 |
| 是否有"被估计量进门的判据" | S1 修后无；M4 的量测值用 `v_gps − b_dop` 是**观测值**不是门，允许 |
| 内层 χ² 是否与外部门混淆 | 混淆了，已在 M5 拆开 |
| 气压门是否引用了 EKF 输出 | 是（M4），已改 |

| 门的下游写/上游读顺序 | 通过（第 8 步写 → 第 7 步下一帧读） |
| 姿态参考的引用是否自洽 | 通过，但需要 S3 的按门投影才闭合 |
| 气压/加计零偏的 Q 在无观测时是否为 0 | **未写明**，已在 M1/M2 补上 |
