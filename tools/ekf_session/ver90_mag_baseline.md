# VER=90 磁模长基线：恒定固化，删除自愈

## 0. 指令与结论
按用户指令：**基线是恒定的、固化在固件里，不要自愈**。已删除全部自愈逻辑，磁模长门改为与
常数 `1.0` 直接比较（容差 `V5F_MAG_ERR_LIM = 0.10`）。

这不是"再调一个阈值"，而是把**物理归属**摆正：
- 标定把 `A/C` 归一化成 `|f| ≡ 1`（`V5F_MAG_A_INIT` 的归一化说明）；
- 硬铁是**安装**的属性，正确安装下 `|f|` 恒为 1；
- 场次变化 = **标定不再匹配安装 ⇒ 必须重标**，而不是让门跟着漂。

旧逻辑（偏离 < 门限时以 ALPHA 慢跟随 + 持续偏离超过 `MAG_NORM_REBASE`(1000 周期≈2.9 s) 就把基线
重定到当前值）本意是吸收"场次常数偏差"，但**外部铁磁干扰只要持续 3 s 就会被吸成新基线** ⇒ `dev`
归零 ⇒ 门重开。

## 1. 证据（VER=89 夹具 90°/180° 采集，231,963 帧 / 28.89 s，`fw_tag` → VER=89）
夹具水平绕竖轴转，全程 accel_z ≈ +0.9998（水平）。真值：`|f| ≡ 1`、磁场在导航系里的方位角恒为
磁偏角 −7.53°。

| 量 | 值 |
|---|---|
| `|f|`（col45 `mag.mag_norm`） | **0.90 ~ 1.80**（真值必须恒定 1）|
| 器件自身硬铁（本次标定 A/C） | `|C_fw| = 0.0404` 场单位 = **2.1 µT**，与固件旧标定文档的 [+1.39 +1.41 +0.93] µT **一致** |
| 同一物理姿态（旧姿态偏航都是 −180°） | seg#8/#10：`|f|=1.67`、方位角正确；seg#16：`|f|=1.52`、方位角 **+17.5°** |
| `|f|` 超出 1±0.10 的帧里 `mag_used` | **仍开 46.4%**（基线自愈把 >10% 的偏离也接受了）|
| 固件自己的磁新息 `mag_r`(col119) | t=19.0 **17.87°**、t=23.5 **26.89°**，而 `mag_used` 仍 42~54% |
| EKF 与旧姿态的偏航差 | t=19.5 **+10.7°** → t=21.0 **+17.7°**；t=24 **−15.7°** → 末态 **−19.9° 且不恢复** |

三条判据把责任分清了：
1. **不是标定**：本次等效硬铁 2.1 µT 与旧标定一致；而且 t=0~18 s 段 `|f|≈0.98`、导航系方位角
   = −7.5°（正确），说明标定 + 开机对齐是自洽的。
2. **不是姿态相关误差**：同一物理姿态在不同时刻给出 0° 与 17.5° 两种结果 ⇒ 只能**时变外部干扰**。
3. **是"持续干扰被自愈吸收"**：`|f|=1.52` 时门仍开 46~54%，EKF 于是跟着错的磁北走并保持。

## 2. 代码改动（`proc_ekf.c`，`s_mn_*` 相关块）
```c
float dev, mnow = h->mag.mag_norm;
dev = fabsf(mnow - 1.0f);
s_mn_ok = (uint8_t)(dev < V5F_MAG_ERR_LIM);
gate->ekf_mag_yaw = (uint8_t)(s_mn_ok && (V5F_EKF_YAW_OBS_EN != 0u));
s_mag_gate = gate->ekf_mag_yaw;
```
删除：慢跟随 `s_mn_lp += (...)·ALPHA`、重定基线 `s_mn_lp = mnow`、自举 `s_mn_seen`。
`s_mn_lp / s_mn_bad / s_mn_seen` 声明保留（文件级 static，未使用不产生告警）并标注 `★VER=90 起不再使用`。
同时修掉一个副作用：旧自举在开机时会把 `mag_norm=0`（IST 还没出样本）锁成基线造成死锁（作者注释里的
VER=22 事故）；改成与常数 1.0 比后该路径自然消失——没有样本时 `dev=1` ⇒ 门关，来样本即自动恢复。

**记录**：门的输入 `|f|` 本来就在 **col 45 `mag.mag_norm`** 上报（`jf_load.py` 里已有 `'mag_norm': 45`），
参考端是写死在头文件里的常数 `1.0`，所以"门 + 输入 + 参考"三件都已记录，**无需新增列**。

## 3. 预期效果（在这段污染数据上实算）
| 区间 | 旧实际 `mag_used` | 新规则（`|f|−1<0.10`）|
|---|---|---|---|
| 全程 | 48.7% | 57.3% |
| t=0~10（干净，`|f|`中位 0.988） | 48.7% | 68.1% |
| **t=19~21.6（方向偏 +17.5°，`|f|`=1.53）** | **47.0%** | **0.0%** |
| t=23.9~28.9（方向偏 −20°，`|f|`=1.12） | 51.4% | 20.7% |

⇒ 被拽走 17.7° 的那一段**彻底关门**（偏航交回陀螺）；t=24 之后那段还留 20.7% 的开口。

## 4. 诚实的残留敞口（下一步的题目）
`|f|` 在 1±0.10 带内、但**方向**已偏 19° 的帧仍会被接受（t=23.9~28.9 就是这种）。仅凭磁模长
判据无法覆盖它——要再进一步需要**方向判据**：
1. **磁场在机体系里的转动 vs 陀螺积分**：干净磁场下二者只差测量噪声；干扰出现时磁场自身在变。
   固件已有 `s_mag_dth`（自上次磁样本以来的机体转动积分，用于陈旧补偿），可据此算残差。
   注意：单样本残差被噪声压住（≈0.35°/样本），要积累到 0.5~1 s 的窗才能把 17° 的畸变从噪声里分出来。
2. 或用旧链（纯陀螺）姿态做**独立航向参考**：`azi_nav(旧姿态)` 应恒等于磁偏角，实测该量在
   t=0~18 是 −7.5°、污染段跳到 +10.0/−27.5° ⇒ 这是最直接的判据，代价是耦合了旧链（其偏航零点与
   EKF 差一个开机对齐角，且自身有 ~0.02°/s 的慢漂）。

## 5. 操作规则（重要，写进流程）
- **门开不了就是重标**：若 `mag_used` 长期 ≈ 0% 且 col45 `mag.mag_norm` 明显偏离 1，说明该安装的
  硬铁与标定差 >10% ⇒ 重新标定，**不要**期待固件自己漂过去。
- **标定/验证采集必须在干净磁环境里做**：判据是**慢速转一整圈时 col45 的 `|f|` 波动 < 2~3%**
  （干净场次实测 0.95~1.05）。本次夹具采集 `|f|` 0.90~1.80 ⇒ 环境里有铁磁物（近处钢件/工具/磁座等），
  这种数据既不能用于标定、也不能用于验证航向。
- 本次采集**不可用于调参**：污染是环境造成的，按它调 R/门限只会把错误学进去。
