# VER=89 门控/遥测修正（倾角重力门 + 磁修正量遥测）

## 0. 一句话
两个待办：① 磁修正量遥测在提前返回路径上不清零（遥测说谎）；② 倾角(重力)门的转动判据用 2 dps
（比物理要求严约 30 倍，代价是磁被暂停 54%）。**我原先记的第②条根因（"level_dps 含 ω_z，应改成
i<2u"）被数据否决**：离心项 a_c = ω²·ARM 对三轴转动一律成立，判据必须含 ω_z；真正的问题是阈值。

## 1. 审计方法（先证列映射，再谈结论）
数据：`R:\raw_v9.bin`（VER=87，544,208 帧 / 67.78 s，未重启）。
- 重建 `level(3轴, 128帧=16ms 滑窗均值)` 与上报 col 7 对比：中位差 3e-4 dps ✓
- 重建门 `acc_valid(flags bit5) && |am2−1|<0.06 && (level<2 || ac_bypass(bit10))`
  与上报 `grav_ok`(col 152) 一致率 **99.16%** ✓（余下 0.84% = 加计削顶 sat、窗未满、坏帧）
  ⇒ 列映射与判据理解正确，下面的分解才有意义。

## 3. 修正 1：`ekf_m7_mag` 提前返回不再吐陈旧 `mag_dq*`
`proc_ekf.c` 该函数有 8 条提前返回（量纲守卫、几何死点、`mh2` 守卫、位移死区、倾角参考暂停、
样本未更新…），旧版只在"样本未更新"和"开机锚点"两条里写 `s_mag_dq*`，其余把上一周期的值留进遥测。
实测后果：`mag_dqz` 长期显示一个**并不存在**的常量注入（约 0.1745°/周期 → 0.5 s 累积 60.9°），
据此我曾误判"磁在剧烈段注入 143°/s"。修法：把三行清零放到**入口门之前**（门关时"本周期磁修正量"
本来就是 0，这是事实而非补丁）。所有 8 条路径现在都吐真值。

## 4. 修正 2：倾角门改物理预算 + 把 a_c 写进 M6 的 R
旧版 M6 的 R 是**固定** `V5F_EKF_TILT_SIG_RAD²`（0.5°²），离心项当 0 —— 于是只能靠把门收到
2 dps 来回避它，代价就是上表的 54% 磁暂停。改为：

1. `v5f_tune.h` 新增（含推导）：
   `V5F_EKF_TILT_AC_ARM_M 0.15f`、`V5F_EKF_TILT_AC_ERR_DEG 1.0f`、
   `V5F_EKF_TILT_WMAX_DPS 61.2f`（= sqrt(g·tan(1°)/0.15)·RAD2DEG）；
   旧 `V5F_EKF_TILT_LEV_DPS 2.0f` 保留但不再进门控（注释已标）。
2. `ekf_m6_tilt`：`R = (TILT_SIG_RAD + eac)²`，`eac(rad) = level_dps²·DEG2RAD²·ARM/g`
   （小角度 atan(x)=x；钳 0.2 rad）。`level_dps` 是 16 ms 窗均值，瞬时 ω 更高 ⇒ 这是**下界**估计。
3. `gate->ekf_tilt` 的阈值换成 `V5F_EKF_TILT_WMAX_DPS`。
4. 旧注释（还在解释 2 dps 的理由）已就地同步，避免文档与代码矛盾。

门只做粗判（削顶、`|a|` 偏离 1 g、极端转速），**带宽来自诚实的 R** —— 这正是"带宽必须来自 R，
不能靠钳增益"的同一原则。

  ② col 151 `mag_hold` 是否大幅下降；③ col 107 `sigma_tilt` 与 |ω| 的相关性。

## 6. 仍未做的（继续记录，不要丢）
1. `|am2−1|<0.06` 对**切向**线加速度完全不可见：|a|=1.03 g 时切向可达 0.25 g（≈14°）——
   这是运动时倾角观测的主要误差源，也是占空比的真正瓶颈。要再进一步需要一个与姿态无关的
   线加速度判据（例如用速度观测残差，但无 GPS 时那条路不存在）。
2. `V5F_EKF_TILT_STEP_MAX_DEG = 1000` 实际等于关闭；若启用，那段"更新后按角度回缩"**不修 P**，
   会造成过自信（与 VER=86 的 Joseph 修正相冲突）。要么保持关闭，要么回缩时同步缩 P。
3. `V5F_EKF_TILT_K_MAX 0.010` 在 Joseph 形式下是**一致**的带宽限制，保留。
4. `proc_acc_gate.c:180` 的速度软 ZUPT 置信度仍用 3 轴 `level_dps`——对"速度"这个门来说含 ω_z
   是保守且合理的（原地偏航仍可能是被搬着走），**本次不动**。
