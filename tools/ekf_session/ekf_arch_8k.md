# EKF 结构规格（8 kHz DMA-RX 中断驱动）

## 0. 时基与所有权

- **唯一时基**：IMU DRDY（`imu.fresh.drdy_tick`，10 ns）。`dt = t_k - t_{k-1}`。
- **唯一消费者**：8 kHz DMA-RX 中断。**预测与更新都只在这里做**，其他任何地方不许动 `x/P`。
- **采样侧**（从核 / RX 阶段）只做一件事：把样本 + `drdy_tick` 写进 `g_v5f_hold`，并置
  `fresh.new_data = 1`。它不认识滤波器，也不做任何时间补偿。

## 1. 每帧固定顺序（8 kHz，一帧一次）

```
DMA1 ISR（每个 IMU DRDY 触发一次，8 kHz）
  ① 取本帧 IMU：陀螺 / 加计 / 温度，t_k，dt_k = t_k - t_{k-1}

  ② 预测 —— 无条件，每帧一次
       x <- f(x, w, a, dt)     // 姿态: (w - bg) 积分; 速度: a_nav - g - ba; 位置; ba/bg/b_baro
       P <- F P F' + Q(dt)
     * 预测不许分频。分频等于把 dt 合并进下一帧，F 的线性化点与 Q 都不再一致。

  ③ IMU/重力**更新** —— 帧同步，每帧必有
       （它同样是"测量更新"，只是调度固定，不是事件驱动）
       与②同一 epoch、同一来源，立即做，**绝不进队列**
       age = t_k - imu.fresh.drdy_tick   (≈0)
       r = f/|f| - R'(x) z ;  H = R'(x) skew(z)  (3 行, 秩 2)
       R = (SIG_TILT0 + k*| |f|/g - 1 |)^2 * I         // |a|≠g 时自动放大, 门位记录
       x += K r ;  P -= K (H P)                        // 便宜写法，别用 (I-KH)P

  ④ 低频源**更新** —— 每帧至多一个，事件驱动，优先级【低频 -> 高频】
       for (i = 0; i < 3; i++) {
           src = ORDER[i];                           // GPS(5Hz) -> 气压(7Hz) -> 磁(197Hz)
           if (队列里没有该源) continue;
           age = t_k - src.drdy_tick;
           if (age > AGE_MAX[src]) { 记"过期丢弃"位; }
           else { r = z - h(x); S = H P H' + R; K = P H' S^-1;
                  x += K r;  P -= K (H P); }
           break;                                    // 一帧只做一个
       }
       // 没有外部新样本 -> 这一帧只有 ①②③，这是常态（>97% 的帧）
       * 低频源稀有，被挤掉要等一整个周期, 所以优先级给低频; 高频源(磁)延后 1 帧
         只占它自己周期(5.26ms)的 2.4%, 无所谓。

  ⑤ 发布上报 / 记门位 / 记新息与本次修正量
```

## 2. 为什么这样是对的

| 性质 | 依据 |
|---|---|
| **滞后有界** | 外部源：帧内相位 ≤125 µs + 等下一帧 ≤125 µs ⇒ **≲250 µs**；IMU 观测：帧内即做，**0** |
| 250 µs 无负面影响 | 300 dps 下 0.075°，静态为 0。换来**最劣中断耗时削平**：一帧最多 1 同步 + 1 异步 |
| **不丢** | 一帧一槽 ≫ 到达率（632 次到达 / 24000 帧 = 2.6%），仿真验证 632 全部被服务 |
| **不重** | `fresh.new_data` 握手，消费即清零 |
| **不伪造** | 观测在**到达后**用它自己那一刻的 `x/P` 融合；IMU 观测帧内即用，无任何"旋到当前时刻"的补偿 |
| dt 与 F/Q 一致 | 预测与中断一一对应，不做 23 分频 |

### 仿真量化（`_sim_order.py`，3 s / 8 kHz，磁 197Hz 气压 7Hz GPS 5Hz）

- 外部源优先级顺序（低频→高频 / 高频→低频 / 先到先服务 / 同帧批处理）**精度完全一样**
  （姿态 0.250° 速度 0.1252，三种顺序与批处理到小数点后三位相同）
- 低频→高频把零延迟给稀有源：GPS max 0 帧、气压 max 1 帧、磁 max 1 帧
- **把加速计观测放进队列（哪怕排最后）**：旋转段姿态 2.138° → **5.952°**、峰值 2.404° → **7.755°**、
  速度 0.1654 → 0.3568。原因：排队滞后 p50 318 帧 / max 632 帧 = 79 ms，
  拿 79 ms 前的 `fm` 配当前姿态 ⇒ **旧观测修新状态**。
  ⇒ **加速计观测必须帧同步，绝不进队列。**

## 3. 各源观测模型（互相独立，各管各的状态列）

| 源 | 维 | 观测 z | h(x) | 修的状态 | R | 外门控（全部外置并记录） |
|---|---|---|---|---|---|---|
| **加计/重力（帧同步，非队列）** | 3（秩 2） | `f/|f|` | `R'(x)·ẑ` | 姿态倾角（`skew(R'ẑ)` 的列） | `(σ0 + k·\|\|f\|/g−1\|)²` | \|a\|≠g / 动态 / 饱和 |
| 磁 | 1 | 重力法向量平面内的**实测磁航向** | 同一平面内的模型场航向 | 仅 `q_yaw`（H 只有第 8 列） | `(0.5°)^2` + 门控放大 | 倾角可信 / 动态 / 标定有效 / 场几何 |
| 气压 | 1 | 气压高度 | `p_z + b_baro` | `p_z`, `b_baro` | 气压噪声 | 动态 / 超时 |
| GPS | 2~4 | 位置 / 速度 | `p`, `v` | `p`, `v` | 按 HDOP/σ | 定位质量 / 新鲜度 |

**H 的秩**：重力观测只有 2 个有效方向（沿重力方向不可观）。用 3 行 `skew` 形式时必须让 R 在不可观方向上有大方差，或直接用 2 维叉乘形式，否则会**伪约束**。

### 3.1 磁融合的门控判据 = **倾角参考是否有效**（不是 |a| 带宽）

几何事实：磁新息对**倾角误差**的灵敏度是 **tan(dip) = b0z/b0h = 2.08**（由标定常数直接算出），
而 H 只保留偏航列 → 倾角误差被 2.08 倍当成偏航激励。所以磁观测的可信度取决于倾角参考：

1. **R 里必须含 `(tan(dip) · sigma_tilt)²` 一项**（sigma_tilt = sqrt(P[6][6]+P[7][7])）。
2. **重力观测连续断开 > 0.3 s（或 sigma_tilt 超阈值）→ 暂停磁更新，并记门位。**
   否则磁更新的倾斜行 `dx[6:8] = P[6:8,8]·r/S` 会在倾角无观测时无界累积
   （k_cap 只夹增益不夹步长：0.015·60° = 0.9°/更新 ≈ 168°/s 的倾斜注入权限）。

**注意**：不要指望"偏航→速度→倾角"这条路——它需要**速度观测闭环**；没有 GPS 时不存在。

仿真实测（多轴同时强旋转 200 dps + 0.25 g 动态，30° 磁注入持续 1.5 s，无 GPS，倾角/偏航 RMS 度）：

| 重力门 | 磁 R 项 | 磁暂停 | 旋转段 | 注入期间 | 末段 |
|---|---|---|---|---|---|
| 无门 | 无 | 无 | 11.79 / 8.87 | 11.68 / 77.54 | 6.75 / 105.13 |
| PX4 带 0.9–1.1g | 无 | 无 | **11.74 / 8.88** | 17.14 / 77.33 | 6.80 / 106.10 |
| 固件门 6%,2dps | 无 | 无 | 1.25 / 0.69 | 61.44 / 58.21 | 84.46 / 36.93 |
| 固件门 | 有 | 无 | 1.08 / 0.56 | 51.96 / 20.01 | 65.59 / 24.58 |
| **固件门** | **有** | **有** | **1.09 / 0.55** | **1.10 / 0.75** | **0.59 / 0.41** |

- PX4 的 ±10% 带宽门**对水平加速度无效**：0.25 g 水平 → |a| = 1.03 g（在带内）但方向偏 14°。
  PX4 靠 `!isHorizontalAidingActive()` 兜底；没有 GPS 时必须用更紧的门（固件现用的 6% + 2 dps）。
- 磁暂停那 39.2% 的帧不融合，换来注入期间倾角 52° → 1.10°、偏航 20° → 0.75°。

记录要求（外门控纪律）：每个源分别记录 **门位 / 新息 r / 增益或修正量 / R / 是否消费 / 样本年龄**，并且"到达但被拒"与"根本没到"必须分开记。

## 4. 必须拆掉的东西

- `mf <- Exp(-s_mag_dth) * mf`：在预测支里伪造观测。删。
- `ist.hdr.cnt` 自锁（`s_mag_cnt_upd`）：改由 RX 的 `fresh.new_data` 事件驱动。删。
- EKF 直接轮询 `g_shm->*.hdr.cnt`：只消费 `g_v5f_hold` 的握手。删。
- 把预测放进阶段分频（`s_stage`）：预测必须每帧。删。
- 滤波器内部一切"分不清就门控"的逻辑：门控全部外置 + 记录。
- **任何把观测排队、滞后融合的做法**（含把帧同步的加计观测塞进异步队列）：
  旧观测配新状态 = 伪造观测。仿真：旋转段姿态 2.14° → 5.95°。

## 5. 中断预算（16 维误差态）

| 项 | MAC/帧 | 说明 |
|---|---|---|
| 稀疏预测（按 F 的 46 个非零展开） | 672 | 稠密是 8192，省 12.19 倍，**严格等价**（P 差 3e-16） |
| 重力观测更新（3 维） | 2545 | 必须写 `P -= K(H P)`；`(I−KH)P` 写法是 5886，比预测还贵 9 倍 |
| 外部源（2.6% 的帧，1 维） | ~800 | 一帧至多一个 |
| **最坏合计** | **~4017 ≈ 28 µs @144 MHz = 22% 占空比** | 现状 27 µs = 21.6% |

协方差**必须每帧原子完成**（不能像现在这样按行摊到 17 帧）：仿真实测降频到 347.8 Hz 会使
速度 RMSE 0.125 → 0.248 m/s（2 倍）、bg 误差 0.93 → 1.61 dps（1.7 倍）、P 偏小 5 倍（过度自信）。
