# V5F 导航 EKF 融合系统设计

> 目标：把 IMU / 磁力计 / 气压计 / GPS 融成一个可用的导航解，输出**重力系世界四元数姿态**、
> 世界系速度与位置（标准单位 m、m/s、m/s²、deg）。所有跨传感器融合一律走**外门控**，
> 一环一门、正确对应、全部上报。落地方式为**影子模式**：先与现有 `proc_attitude` /
> `proc_velocity` 并行跑、全部记录，离线达标后再切。
>
> 本文里每个噪声/阈值都标注来源：**【实测】**= 来自本仓库已有记录的分析；
> **【待实测】**= 必须先量再填，不许猜。

## 0. 坐标系与符号（已逐条从固件核实，不是假设）

| 量 | 约定 | 出处 |
|---|---|---|
| `q = {w,x,y,z}` | **机体 → 导航**，Hamilton 积，右手系 | `proc_attitude.c`：`R(q)·u = (0,0,1)` 求最小旋转；`q ← q ⊗ dq`，`dq` 由**机体**角速度构造 ⇒ 右乘 = 机体→导航 |
| 导航系 `n` | z = 上（重力反方向），x/y 水平；**上电时 x = 机体 x 轴的水平投影** | 同上 |
| `imu.gyro_dps[3]` | 机体系角速度，°/s，已扣离线零偏与逐轴标度 | `proc_gyro_bias.c` |
| `imu.accel_g[3]` | 机体系**比力**（specific force），单位 g，静止时 \|a\|=1、方向 = −重力 | `proc_accel_cal.c` |
| `att.up_ref` | 恒 `(0,0,1)`，导航系竖直参考 | `proc_attitude.c` |
| `mag.mag_f[3]` | 标定后**机体**系地磁单位方向 | `SPI_rx.c` |
| `mag.Bw[3]` | `Bw = R(q) · mag_f` = **导航系**地磁单位方向 | `SPI_rx.c` 487 行注释 |
| `mag.psi_deg` | `atan2(Bw_x, Bw_y)`，**导航系相对磁北的偏航角** | `SPI_rx.c` 161 行 |
| `mag.psi_true_deg` | `psi_deg + D`，`D = V5F_MAG_DECL_DEG = −7.53°`（WMM） | 同上 162 行 |

### 0.1 由约定直接推出的两条结论（设计的关键前提）

**（a）`psi_true_deg` 的变化量 = 姿态的偏航误差。**
`Bw` 是地磁在**导航系**里的表示，地球磁场在导航系里是**固定矢量**；姿态的偏航若有误差 ε，
`Bw` 就被转过 ε。所以 `psi_true_deg` 的漂移直接就是偏航误差的漂移。
【实测佐证】221703 记录里 S1→S4 `psi_true` 阶跃 −12.4°，段内 std 仅 0.64~0.82°（SNR ≈ 18×）。

**（b）EKF 的导航系必须定成真 ENU（x=东, y=北, z=上）——这要求初始化时用磁力计对齐一次偏航。**
`psi_deg = α − ε`：`α` = 地磁在导航系里的方位（常数，只由"导航系朝哪"决定），`ε` = 姿态的偏航误差。
- 若导航系保持"上电时 x 轴的水平投影"这种任意朝向，它与 ENU 差一个**未知的固定旋转** `ψ_N`；
- 而 GPS 给的是 ENU 坐标 —— 两者对不上，位置观测在数学上就是错的；
- 解法：**初始化时用磁力计把导航系 x 轴定到真 ENU**，于是 `α ≡ D`（磁偏角）成为已知常数。

★ 必须把两件事分开，别混：
  - **一次性初始化**：只在 `up_ref_ok` 建立那一帧，把"导航系朝哪"定下来；
  - **持续闭环**：**在 EKF 内部**把磁偏航当一道正常的、带门带协方差的观测（M7，默认开）。

★ **现有 `proc_attitude` 链继续不闭环**（`SPI_rx.c:136` 的「★ 不写回 att.q：磁力计不闭环」保持原样）。
  分工是：旧链 = 陀螺 + 重力；**EKF = 全融合（含磁偏航）**。那一路"磁力计自己认为的维度"
  本来就是为 EKF 准备的。

**（c）★ 一个必须写进代码的坑：日志里的 `psi_deg` / `psi_true_deg` 不能当 EKF 的观测。**
`SPI_rx.c:142~161` 的 `Bw = R(att.q)·mag.f` 用的是**旧链的姿态** `att.q`，
所以 `psi_deg` 是**旧姿态的函数**，不是纯传感器量。EKF 若拿它当观测，等于拿旧链的输出喂自己，
既不正交也会在切换时引入旧链的 yaw 误差。
**EKF 必须自己取 `mag.mag_f`（机体系，ch 49~51）配自己的 `q̂` 算预测观测**（见 §3 M7 的模型）。

## 1. 状态、频率、内存

### 1.1 误差状态（16 维，全局/nav 系误差定义）

```
δx = [ δp(3)  δv(3)  δθ(3)  δba(3)  δbg(3)  δb_baro(1) ]
索引   0..2    3..5    6..8    9..11   12..14     15
```

- `δθ` 用**导航系（全局）误差**：`q_true = Exp(δθ) ⊗ q̂`。
  选它的理由：磁偏航观测的雅可比正好是"只有第 8 项 = −1"（§4.2 的推导），
  且偏航失效的行为干净地局限在 `P[8][8]`，便于上报与观察。
- `δba`：加计零偏**残差**（在离线常量 `V5F_ACCEL_BIAS_LSB_*` 之上），m/s²。
- `δbg`：陀螺零偏**残差**（在 `V5F_GYRO_BIAS_LSB_*` 之上），dps。
- `δb_baro`：气压高度零偏，m。**必须有的一个状态**：气压计相对精度极好但绝对基准未知且随天气漂移。

★ EKF **不使用** `imu.gyro_dps` / `imu.accel_g`（那两个已经被 `proc_gyro_bias` /
`proc_accel_cal` 的在线牵引改过），而是从原始 `gyro_lsb` / `accel_lsb` 出发、
只套**离线标定常量**。否则 EKF 的零偏状态与旧牵引环互相污染、且不可辨识。
这与门B 坚持"用离线常量校正后的角速度"是同一条理由（避免自环）。

### 1.2 解算频率

| 项 | 值 | 理由 |
|---|---|---|
| IMU 采样 | 8021.9 Hz | 既有时基 |
| **EKF 步进** | **每 16 帧 = 501.4 Hz** | 16 维 `F P Fᵀ` 约 1.6e4 flops；501 Hz 下均值 8 MFLOP/s。8 kHz 直接跑要 ~1.3e8 flops/s，不可行 |
| 预积分 | 在 16 帧内累加 `Δθ`、`Δv` | 姿态用精确 `Exp(Δθ)`，不丢 8 kHz 信息 |
| 位置更新 | 0.3 Hz（`V5F_GPS_POS_DECIM_HZ`） | GPS 位置误差自相关 5 s 以上，提高率无信息增量 |
| 气压更新 | 6.1 Hz（`V5F_BARO_AVG_W=32` 后的带宽） | 平均后 σ=0.09~0.13 m |
| 速度更新 | 11.16 Hz（RMC 率） | |
| 重力/倾斜更新 | 每 EKF 步（501 Hz）但受门控 | 门B 实测 100% 有效 |

## 2. 预测

### 2.1 预积分（每帧，16 帧一轮）

```
ω_k = (gyro_lsb_k − BIAS0_LSB) / g_v5f_gyro_lsb_per_dps      [dps] → rad/s
f_k = (accel_lsb_k − ACC_BIAS_LSB) / g_v5f_accel_lsb_per_g   [g]  → m/s²
Δθ += ω_k·dt_k
Δv += R(q̂)·f_k·dt_k                       (用本轮起点的 q̂ 做一次，或分段更新)
```

一阶圆锥/划桨补偿（可选，`V5F_EKF_CONING_EN`，默认 0）：`Δθ += ½ Σ (θ_k × θ_{k+1})`。
501 Hz 下 16 帧 = 2 ms，500 dps 时单步转 1°；对飞手足够，先不做，留开关。

### 2.2 标称状态推进（EKF 步）

```
g_n = (0, 0, −9.80665)                     m/s²
a_n = R(q̂)·f_avg + g_n − R(q̂)·ba
v  ← v + a_n·dt_e
p  ← p + v·dt_e + ½·a_n·dt_e²
q̂  ← q̂ ⊗ Exp(Δθ)
b_baro 不变
```

### 2.3 误差状态转移（连续 → 离散，一阶 `F = I + A·dt_e`）

```
δp' = δv
δv' = −[R f]× δθ − R δba
δθ' = −R δbg
δba' = 0        δbg' = 0        δb_baro' = 0
```
`dt_e = 2 ms`，一阶足够（二阶项 ~2e-4）。

### 2.4 过程噪声 Q（对角块）

| 块 | 表达式 | 数值 | 来源 |
|---|---|---|---|
| `Q_θθ` | `σ_g²·dt_e` | σ_g = 0.1224 dps = 2.136e-3 rad/s | **【实测】** 151 s 静止记录 |
| `Q_vv` | `σ_a²·dt_e` | σ_a ≈ 0.0217 m/s² (= 2.21 mg) | **【实测】** 静止 \|a\| std 0.00221 g |
| `Q_ba` | `σ_ba_rw²·dt_e` | **【待实测】** | 逐差/Allan on `accel_lsb`（静止长记录） |
| `Q_bg` | `σ_bg_rw²·dt_e` | **【待实测】** | 逐差/Allan on `gyro_lsb`（同上） |
| `Q_baro` | `σ_baro_rw²·dt_e` | **【待实测】** | 长记录里 `baro_press_avg` − 气压高度的低频漂移率 |

★ 三个随机游走 σ **必须实测后再填**，不许用数据手册值：它们直接决定偏航方差涨多快、
以及 GPS 位置能不能被平滑掉。方法同当年标磁力计：长静止记录逐差 + Allan。

### 3.1 三条必须写进代码的注意

1. **M4 的 speed 与 course 是同一个接收机解算出来的，不能当两个独立观测。**
   所以是**一个 2 维观测** `[v_E, v_N]`，不是"速度大小 + 航向"两个 1 维观测
   （后者会人为把自由度算成 2 份且把 course 的低速噪声当独立信息）。
2. **M5 不能只用 `is_static`。** 【实测】等效原理下匀速平移对陀螺和加计都不可见：
   某次 60 s 匀速走动里 `is_static` 是 **100%**。所以 ZUPT 门必须再加
   "GPS 多普勒速度（扣掉偏置后）< 0.3 m/s"约束 —— 走动时 GPS 会给出 >1 m/s，静止给 ~0。
   这条组合是整个系统里**最重要的一道保险**。
3. **`b_dop`（多普勒直流偏置）在静止时用一阶牵引估**，不做成状态。
   【实测】静止真值 0，实测均值 **+0.25…+0.55 m/s**（场次相关，234804 是 +0.346、
   235508 是 +0.544），std 0.15~0.29。做法与陀螺零偏牵引同构：门 = `ekf_zupt`，
   `b_dop += (v_gps − b_dop)·dt/τ_dop`，τ 取 5 s，只在门开时牵引。
   这样 M5 反过来又让 `b_dop` 可观测 —— 互锁是良性的（不是证据自环）。

### 3.3 C/N0 加权（M1/M4）

`C/N0` 是这次天线实验里唯一能解释"几何极好却仍差 6 m"的量。加权方式：

```
R_pos_eff = R_pos · clamp( (C0_ref / C_N0_sky)² , 1, 9 )      C0_ref = 33 dBHz
```
【实测】C/N0 27.8→28.6 dBHz 时 UERE 反推 7.46→3.74 m。C/N0 低 = 弱信号/多径 = UERE 大，
这是物理上正确的加权方向，而且比任何滤波调参都更直接。
★ 依赖：`gps_publish_gsv` 的**轮次聚合**必须先修（现在一个轮次有 4 个 talker，
只报了最后一个，卫星数被低估到 1/8）—— 见 §7 待办。

## 4. 偏航环：在 EKF 内闭环

### 4.1 分工（别搞混）

| 环节 | 磁力计的角色 |
|---|---|
| `proc_attitude`（旧链，处理函数 3） | **不闭环**。`SPI_rx.c:136` 明写「★ 不写回 att.q：磁力计不闭环」，只做陀螺积分 + 重力倾斜修正 |
| `mag.psi_deg` / `psi_true_deg`（旧链输出） | "磁力计自己认为的维度"，由**旧链 att.q** 算出，仅供观察与离线对照（见 §0.1(c)：**不能喂给 EKF**） |
| **`proc_ekf`（本设计）** | **闭环**：M7 是滤波器里一道正常的、带门、带协方差的偏航观测 |

### 4.2 观测模型（含符号推导）

导航系 = 真 ENU（x=东, y=北, z=上）。地磁在导航系里的真值：
```
B_n = [ cos(I)·sin(D),  cos(I)·cos(D),  −sin(I) ]        单位矢量
```
【实测】本地 `D = −7.53°`、`I = +53.74°`、`F = 52.05 µT`（WMM）。水平分量的方位 `atan2(B_x, B_y) = D`。

EKF 用**机体系原始磁场**配自己当前的 `q̂` 算预测观测：
```
B̂ = R(q̂) · mag_f                      (mag_f = 标定后机体系单位方向, ch 49~51)
h(x̂) = atan2( B̂_x, B̂_y )              [度]
z    = D                                ← **已知常数**，不需要任何在线量
r    = wrap180( z − h(x̂) )              ← 必须缠绕：psi 会跨 ±180
```
线性化（`q_t = Exp(δθ) ⊗ q̂` ⇒ `B_n = B̂ + δθ × B̂`；`δθ` 索引 6,7,8，8 = 偏航）：
取 `δθ = (0,0,δz)` 得 `B_n,x = B̂_x − δz·B̂_y`、`B_n,y = B̂_y + δz·B̂_x`，于是
```
d h / dδz = −1     ⇒    H = [0 … 0, −1 (第 8 项), 0 … 0]      度/度（换弧度乘 57.29578）
```

**关键性质**：`H` 只挂在偏航那一项，且**与水平分量大小无关** ⇒ 这道观测**只修偏航、不碰倾角**。
所以【实测】的倾角异常（测得 dip 63~64° vs WMM 53.74°）**不会**污染姿态 ——
这正是选"水平方位标量"而不是"三维磁场矢量"观测的原因（后者会把 dip 误差灌进倾角）。

### 4.3 初始化（一次性）

在 `acc_valid ∧ stat.valid ∧ is_static ∧ ||a|−1| < 2%` 首次成立那一帧：
```
1. 用重力定倾角：最小旋转使 R(q̂)·f̂ = (0,0,1)               （与 proc_attitude 同法）
2. 用磁力计定偏航：使 h(x̂) == D  ⇒ 导航 x 轴指向真东，α ≡ D 成为已知常数
3. p = 0; v = 0; ba = 0; bg = 0
4. b_baro = h_baro(now)                     （气压高度此刻映射到 p_z = 0）
5. P0 = diag(σp0², σv0², σθ0², σba0², σbg0², σbaro0²)
     σθ0(x,y) = 0.5°   （对齐残差实测中位 0.49°）
     σθ0(z)   = 3°     （磁航向初始化误差；此后由 M7 持续收紧，门关时才按 Q_bg 增长）
     σbaro0   = 5 m    （气压绝对基准未知，靠 M2 慢慢收敛）
6. 记录 ENU 原点 (lat0, lon0)，GPS 位置转成相对原点的米
```
第 2 步是**唯一**用磁力计定朝向的地方，且只定一次。

### 4.5 门与失效行为

- 门 = `mag.trust` ∧ `|r| < 3σ`。`mag.trust` 已含 `mag.ok`（|y| 模长一致性）和
  `|a_lin| < 0.05 g`（倾斜可信）；门统计一律来自这些**离线常量**，不取滤波器自己的输出。
- **门关时偏航不更新**，`P[8][8]` 按 `Q_bg` 增长 ⇒ **上报列 111 的 `sigma_yaw_deg` 变大**，
  下游据此知道"航向现在不能信"。这是**失效可观测**，不是静默失效。
- 【实测】干扰段磁残差 std 达 **27°**（准静态段只有 0.64~0.82°）⇒ `|r| < 3σ` 的 χ² 剔除
  **必须在**，不能只靠 `mag.trust`。

## 5. CPU 与内存预算

### 5.1 计算量

| 项 | flops | 频率 | 均值 |
|---|---|---|---|
| `F P Fᵀ` (16×16×2) | ~1.6e4 | 501 Hz | 8.0 MFLOP/s |
| 观测更新（M1~M6 平均一次 3 维） | ~3e3 | ~520 Hz | 1.6 MFLOP/s |
| 预积分 | ~20 | 8022 Hz | 0.16 MFLOP/s |
| 合计 | | | **≈10 MFLOP/s** |

【实测基线】现有 ISR 13~15 µs p50、15~17 µs max（占 124.7 µs 的 11~14%）。

### 5.2 尖峰抑制：方差传播按行分帧

`F P Fᵀ` 一次做完是 ~1.6e4 flops，在 400 MHz 单精度 FPU 上约 **20~40 µs** —— 单帧尖峰
会把 ISR 推到 ~55 µs。改成**把 16 行摊到 16 帧**（每帧 1 行，约 512 flops ≈ 1~3 µs），
在一个 EKF 周期的最后一帧完成并随即做更新：

```c
/* 每帧只做 p_row 行：G = F·P 的第 p_row 行 */
for (j = 0; j < 16; j++) { s = 0; for (k = 0; k < 16; k++) s += F[p_row][k]*P[k][j]; G[p_row][j] = s; }
/* 同帧随后做 (G·Fᵀ) 的第 p_row 行，累加 Q，写回 P[p_row][:] */
```

内存：`F`(16×16) + `P`(16×16) + `G`(16×16) + 预积分 + 状态 ≈ **3.5 KB**，V5F 可承受。
`-Ofast -ffunction-sections` 已在用；矩阵乘用固定上界的 `for` 循环、避免任何动态分配。

**另需每步做一次 `P ← (P + Pᵀ)/2` 对称化**（float32 下防漂移，256 ops）。

★ 上面的时钟前提（400 MHz）**未核实**，落地第一步就是量 `s_dma1_irq_us` 在 EKF 打开前后的
分布，尖峰 >40 µs 就把 EKF 率降到 250 Hz（每 32 帧）或把行块再切细。

## 8. 验证计划（影子模式，达标前不影响任何现有输出）

**判据一：NIS 一致性（最硬的一条）**
归一化新息平方 `NIS = rᵀ S⁻¹ r` 应服从 χ²(维数)：
- 位置（2 维）：均值应 ≈ 2；速度（2 维）≈ 2；气压（1 维）≈ 1；重力（3 维）≈ 3。
- `均值 >> 维数` ⇒ R 给小了（观测比声明的差）；`<< 维数` ⇒ R 给大了（浪费信息）。
这是唯一能客观判断 Q/R 配对的办法，**必须逐维看，不能只看总误差**。

**判据二：静态不漂**
静止 ≥60 s：`ekf.p` 的水平漂移应显著小于 GPS 原始游走（原始 2D RMS 4~6 m）。
这一条就是 EKF 存在的意义。

**判据三：与既有解算对照**
- `ekf.q` vs `att.q`：差值应只是倾斜修正；两边都算 `res_g`（比力 vs 姿态预测的重力夹角）
  并比较。既有链路已实测 `res_g` 中位 0.49°。
- `ekf.v` vs `vel.v_nav`：既有 `proc_velocity` 的孪生仿真保真度已验证到 1.276e-3 m/s。
- `ekf.p` 与 GPS 原始轨迹、与气压高度三者对照。

**判据四：门的行为**
每一道门的开启比例必须与物理预期一致（例如静止时 `ekf_zupt` 应 ~100%、
走动时应 <10%）。门统计数据**必须来自离线常量**，不许取滤波器自己的输出（防自环）。

**判据五：偏航环的行为（M7 与其门正确对应的直接检验）**
- **门开时**：`ekf.q` 的偏航收敛到磁力计给的方向，`sigma_yaw_deg` 单调**下降**并稳定在
  【实测】量级（准静态段 0.7° 左右）；
- **门关时**（遮挡/拔掉磁力计，或人为抬 `|a_lin|` 越过 `V5F_MAG_ALIN_LIM`）：
  `sigma_yaw_deg` 按 `Q_bg` **增长**，且 `ekf.q` 的偏航不再被修正；
- **只动偏航的验证**：同一条记录把 M7 开/关各跑一遍，`ekf.q` 的**倾角**分量应几乎不变
  （§4.2 的 `H` 只挂第 8 项，这是该性质的实证）。

## 10. 明确不做的事（避免范围蔓延）

- **不在旧链闭环**地磁：`proc_attitude` 保持不写回（`SPI_rx.c:136` 原样），闭环只发生在 EKF 的 M7。
- **不把**日志里的 `psi_deg` / `psi_true_deg` 当 EKF 观测 —— 它是旧链 `att.q` 的函数（§0.1(c)）。
- **不用**三维磁场矢量观测（会把实测的 dip 异常灌进倾角；用水平方位标量，§4.2）。
- **不引入**导航系偏航偏移状态（用一次性磁初始化 + M7 解决，见 §0.1(b)）。
- **不把** GPS speed 与 course 拆成两个独立观测。
- **不用** `is_static` 单独做 ZUPT（等效原理盲区，必须加 GPS 速度约束）。
- **不用** GPS 高度做高度主观测（std 2.5~5.5 m），它只用来观测 `b_baro`。
- **不在**运行期做 `exp/sqrt` 现算的判据（阈值表一律离线生成，沿用现有纪律）。
