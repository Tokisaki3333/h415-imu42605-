# VER=91：回退倾角门放宽 + 144 µT 伪样本的实测证据

## 1. 决定性测量（本次 13.8 s 采集 `R:\raw_v9.bin`，VER=90，117,001 帧）
按逐帧观察最长的一次异常事件（`raw` 三轴 LSB、`|ω|`、`|a|`）：

```
 t(s)    |raw|   x     y     z     |w|(dps)  |a|(g)
 7.961   175.5   80    19  -155     342
 8.041   177.2   69    37  -159     454     1.02
 8.180   432.9  134    93  -401     196     1.02
 8.240   479.9   86   126  -455       2.4   1.00   <-- 器件完全静止
 8.260   479.9   86   126  -455       2.4   0.99
 8.280   481.0   87   126  -456       4.5   1.00
 8.698   198.9   20   -19  -197      12     0.77   <-- 约 0.35 s 后自行衰减
```

**器件完全静止（|ω| = 2.4 dps、|a| = 1.00 g）时，磁力计读到 481 LSB = 144 µT = 真值 52 µT 的 2.8 倍。**
静止的健康磁力计不可能给出这个值 ⇒ 那一刻**有磁源在器件附近（约 10 cm 量级）**。
本次采集共 **3 段**（0.19 s / 0.19 s / 0.61 s，峰值 2.4~2.8 倍），全部在**手持转动的段落**里；
夹具静置段则始终干净（`|f| = 1.018`）。

排除过的其它解释（都用数据排除，不再重复）：
- **不是载荷错位帧**：坏段里 `col76 fw_tag` 100% 正确、`dt`/`|q|`/`|acc|` 全部正常。
- **不是读取撕裂（混两次转换）**：混合两个矢量的模长只会**变小**，不可能到 2.8 倍；且边界逐帧连续。
- **不是死代码里的重复驱动**：`V3F/User/ist8310.c` 未被任何构建文件编译（`obj/User/subdir.mk` 只有
  `ch32h417_it.c / main.c / mipc_v3.c`），实际链的是 `Common/Common/i2c_soft.c` 的**只读**版本。
- **不是器件硬铁**：本次标定等效硬铁 `|C_fw| = 0.0404` 场单位 = **2.1 µT**，与旧标定文档
  [+1.39 +1.41 +0.93] µT 一致 ⇒ 器件/安装本身是干净的（这一点用户是对的）。

## 2. 我的过失与回退（VER=91）
`VER=89` 我把倾角(重力)门的转速阈值从 `V5F_EKF_TILT_LEV_DPS = 2.0` 放宽到 `WMAX = 61.2 dps`，
当时的依据是"离心项 a_c=ω²·ARM 只有 1°"。**漏掉了主项**：手持运动时加计误差的主项是
**线加速度的切向分量**，它**不改变 |a|**，所以上面的 `|am2−1| < 0.06` 门对它完全不可见
（|a| = 1.03 g 时切向可达 0.25 g ≈ **14° 倾角误差**）。放宽门等于把这类被污染的观测放进倾角更新
⇒ **运动姿态变差、"运动后漂"没改善** —— 与用户观察一致。

**已回退**：`gate->ekf_tilt` 重新使用 `V5F_EKF_TILT_LEV_DPS`（2 dps）。VER=89 新增的常量保留，
`ekf_m6_tilt` 里按 `|ω|` 把 a_c 写进 R 的那段也保留（2 dps 下它 ≈ 0.001°，无害且方向正确）。

**保留**（用户明确要求 / 已被本次数据证明有效）：
- `VER=90`：磁模长基线**恒定固化 = 1.0，不自愈**。实测有效——上述 144 µT 伪样本所在帧
  `mag_used = 0`（100% 被拒），EKF 没有被它们拽走。
- `VER=89`：`ekf_m7_mag` 所有提前返回路径清零 `s_mag_dq*`（纯遥测真实性）。

## 3. 已知代价（留给下一步决策，本次不动）
倾角门回到 2 dps 后，磁更新会像原来一样在运动中常被 `s_tilt_bad_s > 0.3 s` 暂停
（VER=87 实测 `mag_hold` 54%）。"磁更新是否该与倾角门解耦"是**另一个**问题：
VER=87 已把倾角不确定度写进磁的 R（`ra = rb + (tan(dip)·σ_tilt)²`），理论上可以不再硬暂停；
但作者当年的仿真显示硬暂停能压住"倾角无观测时倾斜行无界累积"。**要不要解耦由你定，我不擅自改。**

## 4. 下一步的验收标准（在动固件之前必须先满足）
1. **任何用于标定/评估的采集，全程 `col45 mag.mag_norm`（= 标定后 |f|）必须落在 1.00 ± 0.05 内。**
   本次它是 0.89~2.81 ✗ —— 这种数据既不能标定也不能用来判断算法好坏。
2. 复现本次动作时把**磁性物品拿开 ≥ 30~50 cm**：手机、磁性表扣/手环、磁性螺丝刀、磁座、
   以及任何钢件；手持时尽量用不戴表的手，且不要让器件摆过桌面/夹具的钢件附近。
3. 如果这样做了 `|f|` 仍然跳 ⇒ 就不是环境，而是传感器/读取路径（IST8310 的 set/reset、
   PDCNTL=0xC0、或软 I2C 事务），那时再动固件，且必须带"读数一致性"证据。
4. **要验证"绝对航向"，我需要一个物理基准**：例如开机时器件 x 轴指向某个已知方位（或用转台/
   夹具的已知方位角），并把该方位写进记录。否则我无法从数据判断"北找得对不对"——
   这一点我之前说得太满，抱歉。
