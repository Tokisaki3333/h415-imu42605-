# EKF 中「IMU 姿态」被「磁力计」牵引的完整链条

> 目的：把这一条链从头到尾写清楚，并指出**当前实现与设计注释不一致的那一处**
> （已定位：`proc_ekf.c` 第 821 行 `0x0100u`，与第 657 行注释 `0x01C0` 冲突；
>  由 `_fix_v49_yawonly.py` 引入）。

---

## 0. 状态与误差约定

```
标称 x = [ p(3,m,ENU) v(3,m/s) q(4,机体->导航) ba(3) bg(3) b_baro(1) ]
误差 dx= [ dp(3) dv(3) dth(3, **导航系**) dba(3) dbg(3) db_baro(1) ]   共 16 维
索引:  dp 0..2   dv 3..5   dth 6..8   dba 9..11   dbg 12..14   db_baro 15
```

姿态误差是**导航系（全局）**约定：

```
q_true = Exp(dth) ⊗ q_hat            (ekf_inject: dq=(1, 0.5*dth), q <- dq ⊗ q)
```

**这条约定决定了后面所有 H 的形式，不能混用机体系约定。**

---

## 1. 磁力计提供什么

`h->mag.f[3]`：驱动里标定并归一化后的**机体系**地磁单位矢量（指向磁北且向下）。

## 2. 预测（把机体系量转到导航系）

```
Bn = R(q_hat) · f          (ekf_m7_mag: q_to_R(&s_x[IX_Q], Rt); rot_bn(Rt, mf, Bn);)
```

若 `q_hat` 正确，则 `Bn` 就等于当地真磁场在导航系的表示 `B0`：

```
B0 = ( b0x, b0y, b0z )
   = ( ci·sin(D),  ci·cos(D),  -si )        ci = cos(磁倾角) si = sin(磁倾角)
D = -7.53°   I = 64.32°
=> b0x = -0.0568      b0y = +0.4296      b0z = -0.9013
   水平模 |v0| = 0.4333
```

★ **注意 b0z = -0.9013 远大于水平分量 0.4333 —— 磁场是"陡峭下倾"的。这个数字是后面
  一切几何问题的根源。**

## 3. 观测与新息（2 维水平投影，法向 = 重力方向）

```
z  = ( Bn_x, Bn_y )                     实测量（导航系水平面里的磁场）
h  = ( b0x,  b0y  )                     模型量（常量）
r  = z - h                              标准卡尔曼新息
   = ( Bn_x - b0x,  Bn_y - b0y )
```

代码里先算 `r = Bn - b0`（几何残差，用于诊断 `mag_rx/ry/mag_r` 和整角对齐），
再另算 `rk = b0 - Bn = -r` 喂给 `ekf_update`（VER=72 的符号修正）。

## 4. 雅可比 H —— **这一条链的核心**

由 `q_true = Exp(dth) ⊗ q_hat` 得 `Bn_true ≈ Bn_hat + dth × Bn_hat`，展开：

```
( dth × Bn )_x = dth_y·Bn_z - dth_z·Bn_y
( dth × Bn )_y = dth_z·Bn_x - dth_x·Bn_z
```

在 `Bn ≈ b0` 处线性化，得到 **2×3 的姿态块**（其余 13 列全 0）：

|  | **dth_x（横滚）** | **dth_y（俯仰）** | **dth_z（偏航）** |
|---|---|---|---|
| **Bn_x** | 0 | **b0z = −0.901** | −b0y = −0.430 |
| **Bn_y** | **−b0z = +0.901** | 0 | b0x = −0.057 |

```
s_H[0][6] = 0.0f;  s_H[0][7] =  b0z;  s_H[0][8] = -b0y;     ← 第 682 行
s_H[1][6] = -b0z;  s_H[1][7] = 0.0f;  s_H[1][8] =  b0x;     ← 第 683 行
```

**读法（关键）**：

* 这条观测对**两个倾角方向**的灵敏度是 **0.901**；
* 对**偏航**的灵敏度只有 **0.430 和 0.057**；
* 即 **倾角灵敏度是偏航灵敏度的 2.1 倍与 15.8 倍**。

物理原因：磁场陡峭下倾（b0z=−0.901）。机体一倾斜，就会把那个巨大的垂直分量
"倒进/倒出"水平面，所以水平投影对倾角极其敏感；而偏航只是绕垂直轴转，
只动水平那 0.433 那一部分。

**⇒ 磁力计的水平投影观测，本质上主要是一条"倾角观测"，其次才是"偏航观测"。**

## 5. 增益、掩码、限幅、注入

```
K = P · Hᵀ · S⁻¹        S = H P Hᵀ + R
掩码:  for i: if (!(inj_mask & (1<<i))) K[i][*] = 0;     ← 决定"这条观测被允许动哪些状态"
限幅:  |K[i][j]| <= k_cap                                (M7 取 V5F_EKF_MAG_K_MAX = 0.05)
dx = K · rk
注入:  q <- Exp(dx[6..8]) ⊗ q                            (ekf_inject)
协方差: P <- P - K S Kᵀ
```

## 6. ★ 断点：掩码与实际几何不匹配

**设计注释（第 657 行）**：

```
掩码 0x01C0：H 的倾角列非零，新息按几何分摊到三轴。
```

`0x01C0 = bits 6,7,8` = **两个倾角 + 偏航**。

**实际代码（第 821 行）**：

```c
ekf_update(R, 2u, rk, V5F_EKF_NIS_MAX_MAG_NOSW, &s_nis[4], &s_rej[3],
           0x0100u, V5F_EKF_MAG_K_MAX);
```

`0x0100 = bit 8` = **只有偏航**。（`_fix_v49_yawonly.py` 引入）

### 后果链（这就是"磁力把机体四元数往正北牵引"的机理）

1. `K` 的第 6、7 行被**清零** ⇒ **这条观测被禁止修正倾角**，尽管它对倾角的灵敏度高 2.1 倍。
2. `K` 的第 8 行（偏航）为 `K[8][k] = Σ_j P[8][j]·H[k][j] / S`，
   它通过**协方差交叉项 `P[8][6]`、`P[8][7]`** 把 H 的倾角列 `H[0][7]=b0z`、
   `H[1][6]=−b0z` 也吃了进来。
3. **⇒ 任何一个本质上是"倾角误差"的残差，都被换算成一次"偏航修正"。**
   偏航成了倾角失配的**泄放口**。
4. 倾角误差因为被禁止修正而**一直存在** ⇒ 每个周期都重新泄放到偏航上 ⇒
   **环路持续与陀螺对打**。手转机体必然伴随倾角变化 ⇒ 偏航被拖着乱走 ⇒
   "转不动 / 一直被拉向磁北"。
5. `R_MAX` 从 45 放到 150、以及 VER=74 把 `DEAD` 从 12 删到 0，
   只是把这个错误的力矩**放大了 4.4 倍**（实测 `mag_used` 12.2% → 53.5%），
   不是病因本身。

### 关于"陀螺积分被当成零偏"

* 这条路**在数据里没有发生**：实测 `ekf_bg` 全程 `bg_x/bg_y/bg_z` 中位 0.0000 dps，
  p99 = 1.02 dps（且 `max 18.4` 属上报污染）。
* 能改 `bg` 的只有 M6 倾斜观测（mask `0x7FC0` 含 bit12~14），它对 `bg` 的增益很小。
* 所以用户这条判断目前**未被数据支持**；被支持的是上面第 6 节那条。
